Call Centre Management System Using Queue

About the Project

This project is about managing customer calls in a call centre using a queue in C programming. It helps to add incoming calls and answer them in the order they are received.

Objective

The main objective of this project is to understand how a queue works and how it can be used in a real-life situation like a call centre.

Data Structure Used

Queue using Linked List.

Features

- Add a new customer call.
- Answer the next customer call.
- Display all waiting calls.
- View the next call.
- Display completed calls.
- Exit the program.

Programming Language

C

How It Works

When a new customer calls, their details are added to the queue. The first customer who enters the queue will be answered first. This follows the FIFO (First In, First Out) principle.

Conclusion

Through this project, I learned how to implement a queue using a linked list and how it can be used to manage customer calls.
