Test Cases – Call Centre Management System

Test Case 1: Add a Call

Input: Select option 1 and enter customer ID 101 and name Ravi.
Expected Output: Call added successfully!

Test Case 2: Answer a Call

Input: Select option 2 when a customer is waiting.
Expected Output: The first customer's call is answered and completed successfully.

Test Case 3: Display Waiting Calls

Input: Select option 3 after adding customer calls.
Expected Output: All waiting customers are displayed.

Test Case 4: View Next Call

Input: Select option 4 when calls are waiting.
Expected Output: The first customer in the queue is displayed.

Test Case 5: No Calls Waiting

Input: Select options 2, 3, or 4 when the queue is empty.
Expected Output: A message indicates that no calls are waiting.

Test Case 6: Display Completed Calls

Input: Answer a call and then select option 5.
Expected Output: The completed customer's details are displayed.

Test Case 7: Exit

Input: Select option 6.
Expected Output: The program displays an exit message and terminates.
